[SPOKEN SCRIPT]:
"Let's look at the codebase architecture:
Under 'src/data/', our pipeline extracts 7 physical features per constituent: cyclic
relative coordinates delta-eta and delta-phi, log transverse momentum and energy, relative
momentum fractions, and delta-R, coupled with dynamic masking for variable jet lengths.

Under 'src/models/', we implement two contrasting architectures:
First, a permutation-invariant Deep Sets baseline with O(N) complexity using particle
projections and masked global pooling.
Second, ParticleNet-Lite: a Dynamic EdgeConv GNN. Instead of relying on a static graph,
it recomputes k-nearest neighbor graphs in latent space dynamically at every layer,
learning relational substructure. We implemented this in pure vectorized PyTorch,
eliminating fragile external C++ dependencies.

Both models pass automated unit tests proving exact mathematical permutation invariance
down to machine precision (ten to the minus eight)."
